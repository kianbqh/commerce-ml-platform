E-mail campaign experiment readout¶

I used the Hillstrom / MineThatData experiment to work through an A/B readout: design checks, effect sizes, power, CUPED, and repeated monitoring. There are 64,000 customers and three randomized arms, with visit, conversion, and spend measured over the next two weeks.

This notebook reads the generated report and recomputes the tests, bootstrap intervals, and CUPED values with its recorded parameters. The assertions keep the notebook and command-line analysis in sync.

2. Fixed-horizon effects¶

Binary outcomes use two-proportion z-tests and Wald intervals for the absolute rate difference. Spend uses Welch's t-test. Bootstrap intervals resample customers independently within each arm, using 4,000 draws and seed 42. The 95% intervals are marginal; Holm adjusts the six fixed-horizon p-values as one family.

In [3]:
rows = []
for arm in ['mens', 'womens']:
    sub = df[df.arm.isin([arm, 'control'])]
    t = (sub.arm == arm).to_numpy()
    for metric in ['visit', 'conversion', 'spend']:
        y = sub[metric].to_numpy(float)
        key = f'{arm}_vs_control/{metric}'
        saved = res['tests'][key]
        test = S.two_proportion_ztest(y[t], y[~t], metric) if metric != 'spend' else S.welch_ttest(y[t], y[~t], metric)
        for field in ['control', 'treatment', 'diff', 'ci_low', 'ci_high', 'p_value']:
            np.testing.assert_allclose(getattr(test, field), saved['fixed'][field], rtol=1e-12, atol=0)
        for relative, field in [(False, 'bootstrap_ci_diff'), (True, 'bootstrap_ci_rel_lift')]:
            boot = S.bootstrap_diff_ci(y[t], y[~t], n_boot=params['bootstrap_reps'], seed=params['seed'], relative=relative)
            np.testing.assert_allclose(boot, saved[field], rtol=1e-12, atol=0)
        rows.append({'comparison': key, **test.dict(), 'bootstrap_abs': saved['bootstrap_ci_diff'],
                     'bootstrap_relative': saved['bootstrap_ci_rel_lift'], 'holm_p': res['holm_adjusted_p'][key]})
tab = pd.DataFrame(rows)
adjusted = S.holm(dict(zip(tab.comparison, tab.p_value)))
np.testing.assert_allclose([adjusted[k] for k in tab.comparison], tab.holm_p, rtol=1e-12, atol=0)
print('Verified all 6 fixed-horizon results and both bootstrap intervals per comparison.')

3. CUPED¶

The covariates describe customers before the campaign: past spend, recency, earlier product-line purchases, new-customer status, ZIP category, and channel. The adjustment is fitted on the pooled treatment/control sample. The reported variance reduction is the in-sample residual reduction; Welch intervals compare the adjusted group means. Weak prediction of the two-week outcomes leaves only a small precision gain.

cuped_rows = []
for arm in ['mens', 'womens']:
    sub = df[df.arm.isin([arm, 'control'])]
    t = (sub.arm == arm).to_numpy()
    xs = X.loc[sub.index].to_numpy()
    for metric in ['visit', 'conversion', 'spend']:
        y = sub[metric].to_numpy(float)
        key = f'{arm}_vs_control/{metric}'
        entry = {'comparison': key}
        for name, covariates in [('cuped_history', xs[:, [0]]), ('cuped_multi', xs)]:
            adjusted_y = S.cuped_adjust(y, covariates)
            test = S.welch_ttest(adjusted_y[t], adjusted_y[~t])
            reduction = S.variance_reduction(y, adjusted_y)
            saved = res['tests'][key][name]
            np.testing.assert_allclose([test.diff, test.ci_low, test.ci_high, reduction],
                                       [saved['diff'], saved['ci_low'], saved['ci_high'], saved['variance_reduction']],
                                       rtol=1e-12, atol=1e-14)
            entry[name + '_variance_reduction'] = reduction
        entry['ci_width_ratio'] = res['tests'][key]['cuped_multi']['ci_width_ratio']
        cuped_rows.append(entry)

4. Sequential replay and A/A calibration¶

The data contains no arrival timestamps, so the replay independently shuffles each arm with seed 42. The Gaussian mSPRT uses a fixed 0.10 planning visit rate (sigma2=0.09) and an effect-prior SD of 1 pp (tau2=0.0001). Its exact always-valid result assumes Gaussian observations with known common variance; visits use the Gaussian approximation. The A/A experiment reports empirical rejection frequencies over 400 control-group splits at 20 looks, with an independent seed 43 and Monte Carlo intervals.
